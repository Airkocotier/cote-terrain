La Passerelle PC ⇄ téléphone

Avoir les mêmes fiches sur votre PC et sur votre téléphone : vous préparez au calme sur le PC, vous avez tout au gymnase sur le téléphone. Et ça fait une sauvegarde : si un appareil tombe en panne, l'autre a une copie.

▶ La vidéo arrive très vite sur YouTube En attendant, tout est expliqué ci-dessous, et dans l'appli : ☰ Menu → 🌉 Passerelle → 🎬 Tuto.

1. Activer la bêta

Une seule fois, sur le PC et sur le téléphone :

  1. ☰ Menu → ⚙️ Options.
  2. Cochez 🧪 Fonctions bêta.
  3. Dans ☰ Menu apparaît 🌉 Passerelle PC ⇄ téléphone.

2. Le Wi-Fi en 4 gestes

  1. PC et téléphone sur le même Wi-Fi (ou le PC branché sur la même box).
  2. Sur le PC : Passerelle → Par le Wi-Fi → Envoyer au téléphone, cochez les fiches. Un QR code s'affiche.
  3. Sur le téléphone : Passerelle → Par le Wi-Fi → Scanner le QR code du PC.
  4. C'est fini : les fiches arrivent. Dans l'autre sens, choisissez Recevoir du téléphone sur le PC.

La première fois, Windows demande l'accès au réseau : cochez Réseaux privés. Le PC n'ouvre la porte que 10 minutes, pour un seul échange, avec un code secret contenu dans le QR code. Rien ne passe par internet.
