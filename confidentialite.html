Politique de confidentialité

Application Côté Terrain (Android et Windows) · Dernière mise à jour : 24 novembre 2026

En résumé : Côté Terrain ne collecte aucune donnée. L'application ne demande aucun compte, n'affiche aucune publicité et ne mesure pas son utilisation. Tout ce que vous saisissez reste sur votre appareil.

Qui sommes-nous

Côté Terrain est une application pour entraîneurs de volley, développée par Paul-Marie, entraîneur indépendant.

Contact : contact@coteterrain.fr

Les données que vous saisissez

Vous pouvez saisir des fiches d'exercices, des séances, des équipes (prénoms, numéros de maillot, postes) et des statistiques de match. Ces informations sont enregistrées uniquement sur votre appareil : dans la mémoire de l'application sur Android, dans le dossier de fiches que vous avez choisi sur Windows, dans le stockage de votre navigateur pour la version web (iPhone, iPad, Mac). Nous n'y avons pas accès et elles ne sont envoyées nulle part.

Conseil : pour les joueuses et joueurs, un prénom ou un surnom suffit. Évitez les noms de famille et toute information sensible.

Accès à internet

La version Android utilise le réseau pour la Passerelle Wi-Fi (fonction bêta) et, à votre demande, pour estimer un trajet (voir plus bas) : quand vous la lancez, vos fiches passent directement entre votre téléphone et Côté Terrain sur votre PC, par le réseau de la maison, sans passer par internet ni par nous. Sur le PC, la passerelle n'ouvre une porte sur le réseau local que 10 minutes, pour un seul échange protégé par un code secret. La version Windows fonctionne entièrement sur votre ordinateur ; celle téléchargée sur ce site lit, une fois par jour, un petit fichier public de ce site (version.json) pour savoir si une nouvelle version existe et, si vous acceptez la mise à jour, télécharge l'installeur depuis la page GitHub de Côté Terrain : rien n'est envoyé, et l'hébergeur (GitHub) ne voit que l'adresse IP de l'ordinateur, comme pour toute visite. La version web est chargée depuis ce site, puis fonctionne sans connexion ; vos fiches restent sur votre appareil. Les liens vers des ressources extérieures (vidéos, documents de formation) ne s'ouvrent que si vous appuyez dessus, dans votre navigateur.

Agenda (depuis la version 1.10.15) : quand vous appuyez sur Estimer dans la fiche d'un match, l'appli envoie uniquement l'adresse de départ et l'adresse du gymnase à deux services publics de calcul d'itinéraire : le service de géocodage de l'IGN (Géoplateforme, data.geopf.fr) pour trouver les adresses sur la carte, puis OSRM (router.project-osrm.org, cartes OpenStreetMap) pour la durée du trajet, ou à défaut l'itinéraire de l'IGN. Rien d'autre n'est envoyé (ni noms, ni équipe), et rien n'est envoyé si vous n'appuyez pas sur ce bouton. Itinéraire ouvre Google Maps dans votre navigateur ou l'appli Maps, selon ses propres règles.

Tutos vidéo : les vidéos sont hébergées sur YouTube. Sur ordinateur et dans la version web, rien n'est chargé depuis YouTube tant que vous n'appuyez pas sur Lecture, et le lecteur passe par youtube-nocookie.com ; sur Android, la vidéo s'ouvre dans l'appli YouTube.

Sauvegardes

Sur Android, l'application enregistre automatiquement une copie de vos données dans le dossier Téléchargements/Côté Terrain/Sauvegardes de votre appareil. Vous pouvez désactiver cette sauvegarde dans Options.

Lorsque vous choisissez « Envoyer une copie » ou « Partager », Android vous propose une application de votre choix (par exemple Google Drive ou votre messagerie). Le fichier est alors traité par cette application, selon ses propres règles de confidentialité.

Permissions (Android)

Caméra : uniquement pour scanner un QR code de partage d'une fiche. Aucune photo n'est enregistrée ni envoyée.

Vibration : pour l'alarme du chronomètre.

Signaler un problème

Le bouton « Signaler un problème » prépare un e-mail dans votre messagerie, avec la version de l'application, le modèle d'appareil et les derniers messages d'erreur. Vous voyez ce contenu et vous décidez de l'envoyer ou non. Les e-mails reçus servent uniquement à vous répondre et à corriger l'application.

Enfants

Côté Terrain s'adresse aux entraîneurs adultes. Elle n'est pas conçue pour être utilisée par des enfants.

Supprimer vos données

Vous pouvez supprimer une fiche dans l'application (puis vider la corbeille), ou tout supprimer en désinstallant l'application. Sur Android, les fichiers de sauvegarde restent dans Téléchargements/Côté Terrain ; sur Windows, vos fiches restent dans le dossier choisi à l'installation. Supprimez-les depuis l'explorateur de fichiers si vous le souhaitez.

Vos droits

Comme nous ne détenons aucune donnée vous concernant, il n'y a rien à consulter, corriger ou effacer de notre côté, sauf les e-mails que vous nous avez envoyés. Pour toute question : contact@coteterrain.fr.

Ce site

Ce site n'utilise ni cookies, ni outil de statistiques, ni polices ou scripts chargés depuis d'autres sites. Seule exception : l'image du badge officiel « Microsoft Store » de la page d'accueil est affichée depuis les serveurs de Microsoft, qui reçoivent donc l'adresse IP des visiteurs de cette page. Les vidéos de la page « Tutos » sont hébergées sur YouTube (Google) : rien n'est chargé depuis YouTube tant que vous n'appuyez pas sur le bouton de lecture ; ensuite, la vidéo est lue en mode « confidentialité renforcée » (youtube-nocookie.com), selon les règles de Google. L'hébergeur du site (GitHub) peut conserver des journaux techniques (adresse IP, date de visite) selon ses propres règles.

Modifications

Si cette politique change, la nouvelle version sera publiée sur cette page avec sa date.
